🚀 Aprenda Programação

Plataforma interativa gratuita para ensinar **Pseudolinguagem, C# e Java**
a alunos iniciantes, com um interpretador de pseudocódigo que roda direto
no navegador.

## 🎮 Sistema de gamificação

- **+30 XP** por desafio concluído
- **+50 XP** por módulo avançado
- Barra de progresso visual
- Badges animados a cada conquista
- Progresso salvo automaticamente no navegador (localStorage)

---

## 🔧 Funcionalidades do interpretador

O interpretador de pseudolinguagem suporta:

- Variáveis e atribuição (`<-`)
- Operações aritméticas (`+`, `-`, `*`, `/`, `MOD`)
- Entrada simulada com `LEIA(variavel : valor)`
- Saída com `ESCREVA()`
- Condicionais `SE/ENTÃO/SENÃO SE/SENÃO/FIM_SE`
- Laço `PARA i DE x ATÉ y [PASSO z] FAÇA/FIM_PARA`
- Laço `ENQUANTO cond FAÇA/FIM_ENQUANTO`
- Laço `REPITA/ATÉ`
- Vetores com índice base 1 (`v[1]`, `v[2]`...)
- Funções com `FUNÇÃO/RETORNE/FIM_FUNÇÃO`
- Procedimentos com `PROCEDIMENTO/FIM_PROCEDIMENTO`
